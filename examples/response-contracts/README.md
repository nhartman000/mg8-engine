# Response-contract examples

Choose one complete unit rather than mixing conditions between variants:

- [simple/response.mg8](simple/response.mg8): explicit globals, supplied facts and relatively open prose.
- [ordered/response.mg8](ordered/response.mg8): fixed scientific terms and clause order.
- [grammar/response.mg8](grammar/response.mg8): a single syntactic production.

The GST and G8SON bytes preserve the demonstrated revised contracts. Their manifests use a valid relative trace path and explicitly identify `response-contract-v1`. The `atomic_requirements` and small generation ORK are named profiles, not claims of universal parser support. Use the dedicated response-contract runner, not the legacy generic gate executor.

[Evidence and limits](../../experiments/response-contracts/README.md) include all original divergent and revised matching responses. Do not paste observed answers into generation prompts when repeating the experiment.
